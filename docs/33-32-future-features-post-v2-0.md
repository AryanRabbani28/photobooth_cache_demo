# 32. Future Features (Post V2.0)

## 32.1 Digital Customer Experience (V2.1)

### QR Code Download

After printing, the booth displays a QR code:

```
Your Photo Is Ready!
     [ QR CODE ]
Scan to Download Your Digital Copy
```

The QR code leads to a temporary download page:

```
https://photobooth.com/download/ABC123
```

The link expires after a configurable period (e.g., 24 hours).

### Digital Gallery

Customers can access their photos temporarily via a web page.

### Email/SMS Delivery

Optional feature for customers to enter an email or phone number:

```
Enter Email: [________________]
[ SEND DIGITAL COPY ]
```

## 32.3 Multi-Camera and Multi-Printer Support (V2.3)

After the first hardware integration is stable, support additional hardware:

```
Camera Manager              Printer Manager
├── Canon Adapter           ├── DNP Adapter
├── Nikon Adapter           ├── Mitsubishi Adapter
└── Sony Adapter            └── Windows Print Adapter
```

This makes the system flexible for future booths that may use different hardware.
